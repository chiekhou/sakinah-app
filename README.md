## ✨ Fonctionnalités

- 🎭 **Baromètre d'humeur** - Suivi quotidien de ton état émotionnel
- 📝 **Témoignages** - Partage et lis des expériences (modérés)
- 🧠 **Quiz** - Tests de bien-être et auto-évaluation
- 📚 **Articles** - Contenus éducatifs sur la santé mentale
- 🎬 **Scénarios interactifs** - Situations pratiques avec choix multiples
- 💬 **Chat IA** - Assistant virtuel bienveillant
- 🔔 **Notifications** - Alertes personnalisées
- 👤 **Profil** - Suivi de ta progression

---

## 🛠️ Technologies

### Frontend (Mobile)

- **Flutter** 3.x - Framework mobile cross-platform
- **Dart** - Langage de programmation
- **BLoC** - State management

### Backend (API)

- **Node.js** 18.x - Runtime JavaScript
- **Express** - Framework web
- **PostgreSQL** - Base de données principale
- **MongoDB** - Stockage fichiers
- **Sequelize** - ORM pour PostgreSQL
- **JWT** - Authentification sécurisée

### Services Externes

- **Render.com** - Hébergement backend
- **Supabase** - Base de données PostgreSQL
- **MongoDB Atlas** - Base de données MongoDB
- **Brevo** - Service d'emails
- **Anthropic Claude** - IA conversationnelle
